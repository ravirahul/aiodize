    Agents (MCP)
    
            
    AI apps on this computer
    
            
    Connecting adds Aiodize to the app as a tool, plus a few lines telling it to read your context before working and log what changed after. Each file is backed up first; Disconnect removes only what Aiodize added.
    
            
    
            
    
            
    Claude Desktop, one click
    
            
    Instead of connecting above, you can install Aiodize as a Claude Desktop extension: double-click the file (or drag it onto Claude Desktop, Settings, Extensions), then pick your Aiodize folder and a workspace. Claude Desktop then shows Load my Aiodize context and Log this work in its + menu.
    
            
    
            
    Moving to an AI that can't connect?
    
            
    ChatGPT, Gemini or any chat on the web: export a context pack (your rules, projects and recent work as one Markdown file) and upload or paste it there.
    
            
    
            
    Workspace servers
    
            
    One MCP server per workspace. An agent connected to one workspace can't see the others, and every change it makes is logged and can be reverted.
    
            
    
          
    
          
    Backups
    
            
    A copy of every workspace's notes, rules, statuses and history, once a day, into a folder you choose. Pick another drive, a USB stick or a synced folder like OneDrive. Backups are plain files you can open without Aiodize.

    What Aiodize is
    
              
    A local-first brain for you and your AI agents. Your notes stay plain Markdown files in folders you own. Aiodize draws them as a living graph, shows what Claude and other agents did on each project (sessions, tokens, models, skills), and keeps every workspace's rules so an agent only touches what it should.
    
              
      
                
    • Runs on your computer. The app lives at 127.0.0.1 and reads your files there. The only things it fetches from the internet are the icons of your projects' own websites.
      • 
                
    • Plain files. Markdown with frontmatter, so the same vault still opens in Obsidian or any editor.
      • 
                
    • What leaves this computer: only requests for your projects' own website icons. No account, no analytics, no AI calls of its own; your AI apps talk to Aiodize locally.
      • 
                
    • Nothing silent. Every edit, yours or an agent's, goes into the activity log with the text before it, so you can undo it.
      •

Aiodize started as Ravi's own way to keep track of many projects and the AI agents working on them.
